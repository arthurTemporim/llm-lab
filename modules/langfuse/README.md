# Langfuse

Open source LLM observability platform: traces, sessions, prompts, evals and datasets.

## Overview

| | |
|---|---|
| Documentation | [Langfuse docs](https://langfuse.com/docs), [self-hosting](https://langfuse.com/self-hosting) |
| Image | `langfuse/langfuse:4.54`, `langfuse/langfuse-worker:4.54`, `clickhouse/clickhouse-server:25.12` |
| Container(s) | `langfuse-web`, `langfuse-worker`, `langfuse-clickhouse` |
| GPU | Not used |
| Make target | `make langfuse` |

## What it is used for

* Collects traces of LLM calls (OpenTelemetry / Langfuse SDKs) and shows them in a UI.
* Manages prompts, evaluations, datasets and scores.
* Receives traces from LiteLLM and from your own code.

## Access

| What | Host (browser, CLI) | Inside the `lang` network |
|---|---|---|
| Web UI and API | http://localhost:3001 | http://langfuse-web:3000 |
| Worker health | http://localhost:3030/api/health (localhost only) | http://langfuse-worker:3030 |
| ClickHouse | none on purpose | `langfuse-clickhouse:8123` / `:9000` |

Default login (seeded on first start): `admin@example.com` / `change-me-admin`. Project API keys: `pk-lf-llm-lab-local` / `sk-lf-llm-lab-local`. Change them in `.env` before the first start.

## Quick start

```sh
make create-envs      # creates .env files and generates the secrets
make langfuse         # starts common-services (and databases), then langfuse
make logs-langfuse
```

Wait 30-60 s on the first start (migrations), then check:

```sh
curl localhost:3001/api/public/health   # {"status":"OK","version":"4.54.0"}
```

## Configuration

Edit `modules/langfuse/.env` (created by `make create-envs` from `example.env`), then `make langfuse` to apply.

| Variable | Default | Description |
|---|---|---|
| `LANGFUSE_VERSION` | `4.54` | Tag for the web and worker images |
| `LANGFUSE_PORT` | `3001` | Host port of the web UI |
| `LANGFUSE_WORKER_PORT` | `3030` | Host port of the worker, bound to `127.0.0.1` |
| `NEXTAUTH_URL` | `http://localhost:$LANGFUSE_PORT` | Public URL for auth callbacks; set only behind a proxy and keep it consistent with the port |
| `NEXTAUTH_SECRET`, `SALT` | `CHANGE_ME` | **Secret, required.** Generated by `make create-envs`. Never change `SALT` after first use |
| `ENCRYPTION_KEY` | `CHANGE_ME` | **Secret, required.** Exactly 64 hex chars. Encrypts stored LLM API keys; never change after first use |
| `TELEMETRY_ENABLED` | `false` | Anonymous usage telemetry |
| `LANGFUSE_ENABLE_EXPERIMENTAL_FEATURES` | `false` | Experimental features |
| `AUTH_DISABLE_SIGNUP` | `false` | Disable public sign-up once your user exists |
| `DATABASE_URL` | `postgresql://<POSTGRES_USER>:<POSTGRES_PASSWORD>@postgres:5432/langfuse` | Shared Postgres |
| `REDIS_HOST` / `REDIS_PORT` | `redis` / `6379` | Shared Redis (no password) |
| `CLICKHOUSE_USER` / `CLICKHOUSE_PASSWORD` | `clickhouse` / `clickhouse` | ClickHouse credentials |
| `CLICKHOUSE_URL` / `CLICKHOUSE_MIGRATION_URL` | `http://clickhouse:8123` / `clickhouse://clickhouse:9000` | ClickHouse HTTP and native endpoints |
| `GARAGE_DEFAULT_ACCESS_KEY` / `GARAGE_DEFAULT_SECRET_KEY` | fixed local defaults | S3 credentials. **Must match** `common-services/.env` (`make check-env`) |
| `LANGFUSE_S3_BUCKET` | `langfuse` | Bucket; must be `GARAGE_DEFAULT_BUCKET` of common-services |
| `LANGFUSE_S3_ENDPOINT` | `http://garage:3900` | S3 endpoint inside the `lang` network |
| `LANGFUSE_S3_EXTERNAL_ENDPOINT` | `http://localhost:9100` | S3 endpoint reachable from your browser (presigned URLs) |
| `LANGFUSE_S3_REGION`, `LANGFUSE_S3_BATCH_EXPORT_ENABLED` | `garage`, `false` | S3 region (must be `s3_region` in `common-services/garage.toml`) and batch exports |
| `LANGFUSE_INIT_*` | see `example.env` | Headless org, project, keys and admin user, applied on first start only. Leave empty to sign up in the UI |

## Connections

| Direction | Module | How |
|---|---|---|
| Depends on | `common-services` | Postgres database `langfuse`, Redis (queues, `noeviction`), Garage bucket `langfuse` |
| Depends on | `langfuse-clickhouse` | Same module: analytics store, internal only |
| Used by | `litellm` | Optional trace callback to `http://langfuse-web:3000` |
| Used by | your code | SDK or OTLP to `http://localhost:3001` (from containers: `http://langfuse-web:3000`) |

## Storage

| Data | Where | Survives `down` |
|---|---|---|
| Users, projects, prompts | Postgres database `langfuse` | yes |
| Raw events, media, exports | Garage bucket `langfuse` | yes |
| Traces and scores | ClickHouse named volumes | yes |

## Sending traces

Langfuse v4 ingests traces over **OpenTelemetry (OTLP)**. The legacy `/api/public/ingestion` endpoint only accepts scores, so use a v4-compatible SDK (Python SDK v3+ / JS SDK v4+) or any OTLP exporter.

```sh
pip install langfuse
export LANGFUSE_PUBLIC_KEY=pk-lf-llm-lab-local
export LANGFUSE_SECRET_KEY=sk-lf-llm-lab-local
export LANGFUSE_HOST=http://localhost:3001     # use http://langfuse-web:3000 from containers in the lang network
```

```python
from langfuse import observe

@observe()
def ask(question: str) -> str:
    return "hello"

ask("hi")
```

Plain OTLP (JSON) example:

```sh
AUTH=$(printf 'pk-lf-llm-lab-local:sk-lf-llm-lab-local' | base64 -w0)
curl -X POST http://localhost:3001/api/public/otel/v1/traces \
  -H "Authorization: Basic $AUTH" -H 'content-type: application/json' \
  -H 'x-langfuse-ingestion-version: 4' \
  -d '{"resourceSpans":[...]}'
```

### LiteLLM

The `litellm` module is on the same network. Add to its `.env`:

```
LANGFUSE_PUBLIC_KEY=pk-lf-llm-lab-local
LANGFUSE_SECRET_KEY=sk-lf-llm-lab-local
LANGFUSE_HOST=http://langfuse-web:3000
```

and set `litellm_settings: { success_callback: ["langfuse"] }` in its `models.yaml`.

## Operations

```sh
make logs-langfuse    # follow logs
make down-langfuse    # stop (data is kept)
make databases        # (re)create the postgres databases if missing
```

Full reset (**deletes all Langfuse data**):

```sh
cd modules/langfuse && docker compose down -v
docker exec postgres psql -U lang -d postgres -c 'DROP DATABASE langfuse' && make databases
# Garage only holds the langfuse bucket, so drop its volume; the bucket and key are recreated on start
cd ../common-services && docker compose rm -sf garage && docker volume rm common-services_garage-data && docker compose up -d garage
```

Upgrade: change `LANGFUSE_VERSION`, then `docker compose pull && docker compose up -d`.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `set NEXTAUTH_SECRET in .env` on `compose up` | `.env` is missing or the secrets are empty |
| `network lang declared as external, but could not be found` | Start common-services first (`make common-services`) |
| `database "langfuse" does not exist` | `make databases` |
| Web restarts with ClickHouse errors | `docker compose logs clickhouse`; check `CLICKHOUSE_PASSWORD` |
| S3 / `NoSuchBucket` in the worker | Set `GARAGE_DEFAULT_BUCKET` (common-services `.env`) to `LANGFUSE_S3_BUCKET`, then `docker compose up -d garage` there |
| S3 `SignatureDoesNotMatch` / `InvalidAccessKeyId` | `GARAGE_DEFAULT_*` differ between the two `.env` files |
| S3 `AuthorizationHeaderMalformed` (region) | `LANGFUSE_S3_REGION` must be `s3_region` in `common-services/garage.toml` |
| Images or media do not load | `LANGFUSE_S3_EXTERNAL_ENDPOINT` must be reachable from the browser |
| `Event type "trace-create" is not accepted` | v4 expects OTLP or a v4 SDK (see Sending traces) |
| Port already in use | Change `LANGFUSE_PORT`, or `GARAGE_S3_PORT` in common-services (and `LANGFUSE_S3_EXTERNAL_ENDPOINT`) |

## Notes

* ClickHouse has no host ports on purpose (9000 is commonly taken); it is reachable only inside the `lang` network.
* Object storage is Garage, not the MinIO of the official Langfuse compose. Langfuse supports it as a generic S3-compatible store.
* Defaults are for local development only. Do not expose this setup as is.
