# Common services

Shared Postgres (pgvector), Redis and Garage (S3) used by the other modules. It also creates the `lang` Docker network.

## Overview

| | |
|---|---|
| Documentation | [pgvector](https://github.com/pgvector/pgvector), [Redis](https://redis.io/docs/), [Garage](https://garagehq.deuxfleurs.fr/documentation/) |
| Image | `pgvector/pgvector:0.8.7-pg17`, `redis:8.10.3-alpine`, `dxflrs/garage:v2.5.0` |
| Container(s) | `postgres`, `redis`, `garage` |
| GPU | Not used |
| Make target | `make common-services` (also started by every other module target) |

## What it is used for

* Creates the `lang` network that every other module joins.
* Postgres: databases for `langflow`, `langfuse` and `litellm`, with the `vector` extension for RAG.
* Redis: queues and cache (Langfuse).
* Garage: S3-compatible object storage (Langfuse events, media and exports).

## Access

| What | Host (browser, CLI) | Inside the `lang` network |
|---|---|---|
| Postgres | `localhost:5432` | `postgres:5432` |
| Redis | `localhost:6380` | `redis:6379` |
| Garage S3 API | http://localhost:9100 | http://garage:3900 (path-style access, region `garage`) |

Logins: Postgres `POSTGRES_USER` / `POSTGRES_PASSWORD` from `.env` (the password is generated by `make create-envs`), Garage the `GARAGE_DEFAULT_ACCESS_KEY` / `GARAGE_DEFAULT_SECRET_KEY` from `.env`. Redis has no password. Garage has no web console; use its CLI: `docker exec garage /garage bucket list`.

## Quick start

```sh
make common-services
make logs-common-services
```

Check that it works:

```sh
docker exec postgres sh -c 'psql -U "$POSTGRES_USER" -c "\l"'
docker exec redis redis-cli ping
docker exec garage /garage status
```

## Configuration

Edit `modules/common-services/.env` (created by `make create-envs` from `example.env`), then `make common-services` and the modules that use the changed value to apply.

This `.env` is the **global env file**: the Makefile loads it before every module's own `.env`, and modules reference its values as `${VAR}` (for example `DATABASE_URL=${POSTGRES_URL}/litellm`). Set shared values here only; `make check-env` fails when a module `.env` redefines one.

| Variable | Default | Description |
|---|---|---|
| `LAB_PUBLIC_HOST` | `localhost` | Host name or IP clients outside Docker use. Builds the Garage external endpoint, Langfuse's `NEXTAUTH_URL` and Hatchet's public URLs |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` | `lang` / generated | Postgres credentials, applied only when the volume is created. Keep the password URL-safe |
| `POSTGRES_HOST`, `POSTGRES_URL` | `postgres`, `postgresql://${POSTGRES_USER}:${POSTGRES_PASSWORD}@${POSTGRES_HOST}:5432` | Base connection string; modules append `/<database>` |
| `POSTGRES_DATABASES` | `langflow langfuse litellm hatchet` | Space separated databases created (with `vector`) by `make databases` |
| `REDIS_HOST`, `REDIS_URL` | `redis`, `redis://redis:6379` | Redis inside the `lang` network (no password) |
| `GARAGE_DEFAULT_ACCESS_KEY` / `GARAGE_DEFAULT_SECRET_KEY` | generated | S3 key (`GK` + 24 hex) and secret (64 hex), created at start if missing |
| `GARAGE_DEFAULT_BUCKET` | `langfuse` | Bucket created at every start if missing (one bucket only) |
| `GARAGE_RPC_SECRET` | generated | Internal RPC secret, 64 hex chars |
| `GARAGE_S3_ENDPOINT`, `GARAGE_S3_EXTERNAL_ENDPOINT` | `http://garage:3900`, `http://${LAB_PUBLIC_HOST}:${GARAGE_S3_PORT}` | S3 endpoint inside the network and from browsers |
| `GARAGE_S3_REGION` | `garage` | Must be `s3_region` in `garage.toml` |
| `OLLAMA_URL` | `http://ollama:11434` | Ollama address used by LiteLLM and Open WebUI |
| `LANGFUSE_PUBLIC_KEY` / `LANGFUSE_SECRET_KEY`, `LANGFUSE_HOST` | generated, `http://langfuse-web:3000` | Langfuse project keys, seeded by Langfuse on its first start and used by clients (LiteLLM) |
| `POSTGRES_PORT` | `5432` | Host port of Postgres |
| `REDIS_PORT` | `6380` | Host port of Redis (6379 is commonly taken) |
| `GARAGE_S3_PORT` | `9100` | Host port of the S3 API |

A new database for a new module goes in `POSTGRES_DATABASES`. Other Garage settings (paths, S3 region) are in `garage.toml`.

## Connections

| Direction | Module | How |
|---|---|---|
| Depends on | none | Creates the network |
| Used by | `langflow` | Database `langflow` |
| Used by | `langfuse` | Database `langfuse`, Redis queues, Garage bucket `langfuse` |
| Used by | `litellm` | Database `litellm` |
| Used by | `hatchet` | Database `hatchet` |
| Used by | all | The `lang` network, and the global `.env` values they reference |

## Storage

| Data | Where | Survives `down` |
|---|---|---|
| Postgres databases | `postgres-data` named volume, mounted at `PGDATA` | yes |
| Redis data | `redis-data` named volume | yes |
| Garage objects and metadata | `garage-data` named volume | yes |

Only `docker compose down -v` removes them.

## Operations

```sh
make down-common-services   # stop, keep data
make databases              # create missing databases (idempotent)
make check-env              # verify the global .env and that no module redefines its values
```

Upgrade: change the image tag, then `docker compose pull && docker compose up -d` in `modules/common-services/`. Do not change the Postgres major version without a dump.

## Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `database "x" does not exist` | Add it to `POSTGRES_DATABASES`, run `make databases` |
| `NoSuchBucket` | Check `GARAGE_DEFAULT_BUCKET`, then `docker compose up -d garage` |
| `AuthorizationHeaderMalformed` (region) | The client must use the region `s3_region` from `garage.toml` (`garage`) |
| Port already in use | Change the matching `*_PORT` variable |
| Databases empty after an old lab was recreated | The Postgres volume changed; restore from a `pg_dumpall` taken before |
| `too many clients already` in Postgres logs | The modules' connection pools exceed `max_connections` (200, the `command:` of `postgres` in `docker-compose.yml`). Raise it, or lower a module's pool (for example Hatchet's `DATABASE_MAX_CONNS`) |

## Notes

* Postgres runs with `max_connections=200` (default 100) because every module keeps its own connection pool on it; Hatchet alone uses up to 50.
* Redis runs with `--maxmemory-policy noeviction` because Langfuse (BullMQ) requires it. Keep it.
* The Garage S3 host port is 9100 on purpose to avoid clashes with ClickHouse (9000).
* Garage runs as a single node (`--single-node`) without replication, and creates the default key and bucket at start (`--default-bucket`).
* Garage rejects requests signed for another region than `s3_region` in `garage.toml`.
* Defaults are for local development only.
